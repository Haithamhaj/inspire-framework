## Replit Setup (follow this order)

```bash
# 1. Install all dependencies
npm install next react react-dom typescript @prisma/client prisma \
  openai @anthropic-ai/sdk resend @react-pdf/renderer \
  bcrypt jose zod
npm install -D @types/node @types/react @types/bcrypt \
  tailwindcss postcss autoprefixer

# 2. Initialize Tailwind
npx tailwindcss init -p

# 3. Initialize Prisma
npx prisma init
# Paste the schema from /skills/db.md into prisma/schema.prisma

# 4. Push schema to DB
npx prisma db push

# 5. Run in dev
npm run dev
```

## Cron Job Setup on Replit

The retry queue runs every minute via a protected API route.

**Route:** `GET /api/cron/retry`
**Header required:** `x-cron-secret: <CRON_SECRET>`

**Setup in Replit:**
1. Go to your Replit → "Scheduled Jobs" or use Replit's built-in cron
2. Set schedule: `* * * * *` (every minute)
3. Command: 
```bash
curl -s -X GET \
  "https://your-app.replit.app/api/cron/retry" \
  -H "x-cron-secret: $CRON_SECRET"
```

**Alternative (if Replit cron unavailable):** Use a free external cron service like cron-job.org.

## Rate Limiting

Protect public endpoints from abuse:

```typescript
// src/lib/rate-limit.ts
import { NextRequest } from 'next/server'

const rateLimitMap = new Map<string, { count: number; reset: number }>()

export function rateLimit(
  req: NextRequest,
  limit: number = 10,
  windowMs: number = 60_000
): boolean {
  const ip = req.ip ?? req.headers.get('x-forwarded-for') ?? 'unknown'
  const now = Date.now()
  const entry = rateLimitMap.get(ip)

  if (!entry || now > entry.reset) {
    rateLimitMap.set(ip, { count: 1, reset: now + windowMs })
    return true // allowed
  }

  if (entry.count >= limit) return false // blocked

  entry.count++
  return true // allowed
}
```

**Apply to:**
- `/api/auth/register` → 5 per hour per IP
- `/api/assessments/start` → 10 per hour per IP
- `/api/assessments/[id]/submit` → 10 per hour per IP
- `/api/cron/retry` → protected by secret header only

## Security Checklist Before Launch

- [ ] All API keys in Replit Secrets (not in code)
- [ ] `NEXT_PUBLIC_*` prefix ONLY for values that can be public
- [ ] OPENAI_API_KEY has no `NEXT_PUBLIC_` prefix
- [ ] ANTHROPIC_API_KEY has no `NEXT_PUBLIC_` prefix
- [ ] Admin routes check ADMIN_PASSWORD
- [ ] Cron route checks CRON_SECRET header
- [ ] JWT uses strong random secret (32+ bytes)
- [ ] bcrypt rounds = 12 minimum
- [ ] Passwords never logged or returned in API responses
- [ ] `prisma.user.findMany` always excludes `passwordHash` with `select`

## Common Build Errors & Fixes

| Error | Cause | Fix |
|---|---|---|
| `Module not found: @prisma/client` | Not generated | Run `npx prisma generate` |
| `PrismaClientInitializationError` | DATABASE_URL wrong | Check Replit Secrets |
| `Cannot find module 'bcrypt'` | Types missing | `npm install -D @types/bcrypt` |
| `Error: Text content does not match` | SSR/hydration RTL mismatch | Add `suppressHydrationWarning` to `<html>` |
| PDF generation fails | Missing serverComponentsExternalPackages | Update next.config.ts |
| `JWT_SECRET is not defined` | Missing env var | Add to Replit Secrets |
