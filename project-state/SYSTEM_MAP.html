INSPIRE System Map

Operational map for the migration branch. It shows the current system boundaries, customer flow, database responsibilities, and the main upgrade targets before Supabase deployment and Lemon Squeezy review.

Current System

Frontend

Vite React app in artifacts/inspire-web. Uses Wouter routes and fetches the API through /api.

API

Express server in artifacts/api-server. Mounted under /api.

Database

PostgreSQL through Drizzle in lib/db. Ready in principle for Supabase.

Legacy Deploy

Replit remains the existing running path. New work should be built from this branch first.

Customer Flow

Landing User sees product, price, legal links, and starts assessment.
Auth User consents, registers, logs in, and receives token/cookie auth.
Assessment Draft is created, answers are saved, and open answer is stored.
Generation AI creates report and final copy-ready instructions.
Results User views result, shares it, downloads PDF, or submits feedback.

Database Responsibilities

Already Stored

  • Users and password hashes
  • Assessment answers
  • Final report content
  • Final system instruction
  • Payments and discounts
  • Feedback and share tokens

Missing For Improvement

  • Decision/matrix snapshot
  • Scoring snapshot
  • Prompt version
  • Generation run history
  • Structured failure evidence

DB V2 Target

  • assessment_generation_runs
  • assessment_decision_snapshots
  • Admin evidence review
  • Future customer comparison

Risk And Migration Focus

Mismatch

Payment

Legal pages now mention Lemon Squeezy, but the current billing implementation is PayPal. PayPal should be hidden from the review path before Lemon Squeezy resubmission.

Priority

Admin Review

Admin needs an assessment detail view that connects answers, matrix decisions, generation evidence, final report, final instruction, payment state, and feedback.
