## Auth Architecture

```
Registration flow:
  POST /api/auth/register
    → validate input with zod
    → check consent_given === true (reject if false)
    → check email not already used
    → bcrypt hash password (12 rounds)
    → create user (emailVerified: false)
    → generate verify token → send email
    → return 201

Email verification:
  GET /api/auth/verify-email?token=xxx
    → find user by emailVerifyToken where expires > now
    → set emailVerified: true, clear token
    → return redirect to /login

Login flow:
  POST /api/auth/login
    → find user by email
    → check emailVerified (reject if false, tell them to check email)
    → bcrypt compare password
    → generate JWT access token (7d)
    → generate refresh token (30d) → save to DB
    → set httpOnly cookie: refresh_token
    → return access_token + user info in body

Middleware (every protected route):
  → read Authorization: Bearer <token>
  → verify JWT with jose
  → attach user to request context
  → reject with 401 if invalid/expired
```

## JWT Helpers

```typescript
// src/lib/auth.ts
import bcrypt from 'bcrypt'
import { SignJWT, jwtVerify } from 'jose'
import { cookies } from 'next/headers'
import { prisma } from './db'
import { randomBytes } from 'crypto'

const JWT_SECRET = new TextEncoder().encode(process.env.JWT_SECRET)
const BCRYPT_ROUNDS = parseInt(process.env.BCRYPT_ROUNDS ?? '12')

// ─── PASSWORD ──────────────────────────────────────────

export const hashPassword = (password: string) =>
  bcrypt.hash(password, BCRYPT_ROUNDS)

export const verifyPassword = (password: string, hash: string) =>
  bcrypt.compare(password, hash)

// ─── ACCESS TOKEN ──────────────────────────────────────

export async function signAccessToken(userId: string): Promise<string> {
  return new SignJWT({ sub: userId })
    .setProtectedHeader({ alg: 'HS256' })
    .setExpirationTime(process.env.JWT_EXPIRES_IN ?? '7d')
    .setIssuedAt()
    .sign(JWT_SECRET)
}

export async function verifyAccessToken(
  token: string
): Promise<{ userId: string } | null> {
  try {
    const { payload } = await jwtVerify(token, JWT_SECRET)
    return { userId: payload.sub as string }
  } catch {
    return null
  }
}

// ─── REFRESH TOKEN ─────────────────────────────────────

export async function createRefreshToken(userId: string): Promise<string> {
  const token = randomBytes(40).toString('hex')
  const expiresAt = new Date(Date.now() + 30 * 24 * 60 * 60 * 1000)
  await prisma.refreshToken.create({ data: { userId, token, expiresAt } })
  return token
}

export async function rotateRefreshToken(
  oldToken: string
): Promise<{ userId: string; newToken: string } | null> {
  const record = await prisma.refreshToken.findUnique({ where: { token: oldToken } })
  if (!record || record.revoked || record.expiresAt < new Date()) return null

  await prisma.refreshToken.update({ where: { id: record.id }, data: { revoked: true } })
  const newToken = await createRefreshToken(record.userId)
  return { userId: record.userId, newToken }
}

export function setRefreshTokenCookie(token: string) {
  cookies().set('refresh_token', token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 30 * 24 * 60 * 60,
    path: '/',
  })
}

// ─── EMAIL VERIFICATION ────────────────────────────────

export function generateVerifyToken(): { token: string; expires: Date } {
  return {
    token: randomBytes(32).toString('hex'),
    expires: new Date(Date.now() + 24 * 60 * 60 * 1000), // 24h
  }
}

// ─── AUTH MIDDLEWARE ────────────────────────────────────

export async function getAuthUser(
  request: Request
): Promise<{ userId: string } | null> {
  const authHeader = request.headers.get('Authorization')
  if (!authHeader?.startsWith('Bearer ')) return null
  const token = authHeader.slice(7)
  return verifyAccessToken(token)
}
```

## Zod Validators

```typescript
// src/lib/validators.ts
import { z } from 'zod'

export const RegisterSchema = z.object({
  name: z.string().min(2).max(100),
  email: z.string().email(),
  password: z.string().min(8).regex(/[a-zA-Z]/).regex(/[0-9]/),
  consent_given: z.literal(true, {
    errorMap: () => ({ message: 'You must accept the privacy policy' }),
  }),
})

export const LoginSchema = z.object({
  email: z.string().email(),
  password: z.string().min(1),
})

export const AssessmentStartSchema = z.object({
  project_name: z.string().min(2).max(500),
  project_goal: z.string().min(10).max(2000),
  report_language: z.enum(['ar', 'en', 'both']),
  assessment_type: z.enum(['full', 'mini']),
})

export const AssessmentSubmitSchema = z.object({
  behavioral_answers: z.array(z.object({
    question_index: z.number().int().min(0).max(23),

  scenario_answers: z.array(z.object({
    scenario_index: z.number().int().min(0).max(7),
    choice: z.enum(['a', 'b']),
  })),
  open_answer: z.string().min(20).max(2000),
```

## Consent Page Requirements

The page at `/privacy-consent` must:
1. Show full privacy policy text (what data is collected, how it's used, who sees it)
2. Have a checkbox: "أوافق على استخدام بياناتي / I agree to the use of my data"
3. The "Continue to Register" button must be DISABLED until checkbox is checked
4. After checking: redirect to `/register?consent=true`
5. Registration API must verify `consent_given: true` — reject if false

**Never skip the consent check.** It's legally required and architecturally enforced.

```typescript
  const auth = await getAuthUser(request)
  if (!auth) {
    return Response.json({ success: false, error: 'Unauthorized' }, { status: 401 })
  }
  const { userId } = auth
  // ... rest of handler
}
```

## Rules

- Passwords: bcrypt only, never MD5/SHA, never plain text
- Tokens: httpOnly cookies only, never localStorage
- All tokens expire: access=7d, refresh=30d, email verify=24h
- Revoke refresh token on logout
- Never return passwordHash in any API response — use `select` to exclude it
- consent_given must be true to create account — this is non-negotiable
